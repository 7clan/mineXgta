    21→## Micro-voxel destruction design (core constraint #2)
    22→- Every destructible model (buildings, ground, strata, tunnel shafts) is stored as an indexed high-density mesh (tri edge ≈ 0.85–1.0 m, i.e. "micro-voxel" sampling grid).
    23→- A uniform spatial hash (cell ≈ tri size) maps cells → triangle indices for O(local) carving.
    24→- On tool/explosion: world point → local space, gather candidate tris from overlapped cells, kill tris whose centroid is inside the sphere, radially displace surviving shell vertices (crater lip), compact index buffer, recompute normals (buildings), spawn debris at removed centroids.
    25→- A world-space 1 m occupancy grid records carved cells → used by the hybrid collision engine (player/cars can pass through carved cells = tunneling) and by traffic AI (cars fall into dug road holes).
    26→- Ground dig-down: ground slab → rim shaft walls → infinite strata layers (dirt → stone → deepslate) spawned on demand → bedrock at −64.

    38→- Built shared private helpers to keep the file lean: noise(dur, at), env(g, t0, a, d, peak), farGain(far) (0..1 -> 1..0.06), filter(), osc(), chain(), plus generic burst()/tone() one-shot factories used by all event SFX.
    39→- Guarded every public method with `if (!this.ctx) return` inside try/catch; dispose() stops engine, closes context, nulls all state.
    40→- Iterated 4x on tsc: fixed Float32Array<ArrayBuffer> vs ArrayBufferLike generic mismatch (TS 5.7 lib) by generating the distortion curve inline per boom instead of caching it; compacted file from 538 -> 328 lines.
